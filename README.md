# BESHIK_IOT_BABYSITTER
BESHIK_IOT_BABYSITTER is an IoT-based smart baby cradle inspired by the traditional Uzbek beshik. Built with ESP32, it monitors baby sounds via a microphone and provides real-time audio output through a speaker, helping parents monitor their infant remotely.
👶 BESHIK_IOT_BABYSITTER

BESHIK_IOT_BABYSITTER is a smart IoT-based baby cradle monitoring system designed to assist parents in caring for their infants. The project is inspired by the traditional Uzbek beshik and enhanced with modern IoT technologies to provide real-time monitoring and audio feedback.

🔹 Key Features:

🎤 Microphone-based baby sound detection

🔊 Real-time audio output through a speaker

📡 ESP32-powered IoT control system

💤 Infant comfort and activity monitoring

🖨️ Custom 3D-printed enclosure design

⚡ Standalone power supply via USB / power modules

📦 This project was developed as a final project for the Internet of Things (IoT) course, focusing on practical, real-world application and hardware integration.
